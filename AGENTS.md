# Agent Instructions & Guidelines

## Autonomous Execution Mode (Auto Mode)
- **Automatic File & Directory Management**: Proactively read, create, edit, and organize files and folders without asking for confirmation.
- **Direct Terminal Execution**: Run necessary commands (such as migrations, builds, git status/diff/commit/push) directly to achieve the goal end-to-end.
- **Immediate Action**: When asked to implement or fix something, proceed directly to inspection, modification, verification, and building without pausing for trivial permissions.
